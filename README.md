# Math SRS Bot

Telegram-бот для spaced repetition (SM-2) по формулам и теоремам олимпиадной математики.

## Запуск (Windows, тестовый режим)

1. Получить токен у [@BotFather](https://t.me/BotFather) (команда `/newbot`).
2. Открыть папку проекта в терминале (PowerShell или cmd):
   ```
   cd math_srs_bot
   ```
3. Создать виртуальное окружение (изолированная папка со своими библиотеками, не трогает систему):
   ```
   python -m venv venv
   ```
4. Активировать окружение:
   ```
   venv\Scripts\activate
   ```
   Если PowerShell ругается на политику выполнения скриптов — один раз выполнить:
   ```
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```
   В начале строки терминала должно появиться `(venv)` — окружение активно.
5. Поставить зависимости:
   ```
   pip install -r requirements.txt
   ```
6. Скопировать `.env.example` в `.env` (просто переименовать копию файла) и вписать туда токен:
   ```
   BOT_TOKEN=твой_токен_от_botfather
   ```
7. Запустить бота:
   ```
   python bot.py
   ```
   Если всё ок, в консоли не будет ошибок, и бот начнёт отвечать в Telegram. Останавливается через `Ctrl+C`.

## Команды бота

Бот управляется через **постоянное меню-клавиатуру** внизу экрана (появляется после `/start`) — не нужно набирать команды руками:

- **➕ Добавить карточку** — добавить свою карточку (вопрос → ответ → тема)
- **📚 Повторить** — сессия повторения due-карточек, с прогрессом "карточка 3 из 12" и кнопкой 🗑 удалить прямо во время повторения
- **📋 Список карточек** — список всех карточек с ID и темой (первые 50)
- **📊 Статистика** — сколько карточек всего и сколько due сегодня
- **❓ Помощь** — краткая справка

Слэш-команды тоже работают как раньше (`/add`, `/review`, `/list`, `/stats`, `/delete <id>`, `/cancel`) — можно использовать что удобнее.

`/start` показывает и твой Telegram ID (нужен для `import_seed.py`, см. ниже).

## Пополнение базы без ручного ввода

В `seed_cards.json` лежит 84 карточки с ключевыми теоремами/формулами олимпиадного уровня (неравенства, теория чисел, комбинаторика, геометрия, алгебра) — школьная база (Пифагор, дискриминант и т.п.) намеренно исключена. Залить их одной командой:
```
python import_seed.py <твой_telegram_user_id>
```
Свой `user_id` покажет бот сразу по команде `/start` (не нужен сторонний бот).

## Структура

- `bot.py` — хендлеры aiogram, FSM для добавления карточек и сессии повторения
- `db.py` — SQLite-слой (таблица `cards`)
- `sm2.py` — алгоритм SM-2, оценка сложности упрощена до 3 градаций: 😵 плохо / 🙂 норм / 😎 легко
- `seed_cards.json` — стартовый набор из 84 карточек по ключевым темам
- `import_seed.py` — скрипт заливки seed-набора в базу
- `cards.db` — база данных, создаётся автоматически при первом запуске
